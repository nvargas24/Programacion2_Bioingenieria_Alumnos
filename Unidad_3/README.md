# Unidad 3: Introducción a los Microcontroladores y los Sistemas Embebidos

## Descripción

Esta unidad introduce el concepto de **sistemas embebidos** y el uso de **microcontroladores** en aplicaciones electrónicas.

Se analizan las características principales de estos sistemas y su diferencia con computadoras de propósito general.

## Objetivos

- Comprender qué es un sistema embebido
- Identificar las características de un microcontrolador
- Reconocer aplicaciones típicas de sistemas embebidos
- Reconocer capas de abstracción

## Contenidos

- Caracteristicas de placas de desarrollo
- Herramientas de desarrollo
- Ejercicios de selección de Microcontrolador
- Ejercicios de capas de abtracción
